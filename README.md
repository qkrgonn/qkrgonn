## Quick Start

Just run the `qkrgonn` CLI like this:

```bash

npx qkrgonn
```
```
Options:
  -V, --version   output the version number
  -c, --career    display career
  -g, --github    open github
  -b, --blog      open blog
  -r, --resume    open resume
  -h, --help      display help for command
